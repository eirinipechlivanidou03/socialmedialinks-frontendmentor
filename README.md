# socialmedialinks-frontendmentor

My solution to the [Social links profile challenge on Frontend Mentor](https://www.frontendmentor.io/challenges/social-links-profile-UG32l9m6dQ). A small profile card with a photo, name, location, short bio and a list of social links.

## Features

- Centered dark card with a circular profile photo
- Five social link buttons with a hover state (lime green background)
- Layout adapts to smaller screens (checked in browser DevTools on a phone-sized viewport)

## Built with

- Semantic HTML5 (`main`, `h1`, `p`, `a`)
- CSS custom styling, no frameworks
- Flexbox for centering the text inside the buttons
- Percentage-based widths with `max-width` for a flexible card
- `box-sizing: border-box`
- [Inter](https://fonts.google.com/specimen/Inter) font from Google Fonts

## What I learned

- The difference between `margin` and `padding`, and how browser default margins (for example on `h1`) add extra space
- How `box-sizing: border-box` makes `width` include padding and border
- Why `width` in percentages together with `max-width` helps a layout shrink on small screens
- How to compare my page with the design using the browser DevTools
